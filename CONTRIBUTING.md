# Contributing

Contribuzioni benvenute! Questo è un progetto educativo, ogni miglioramento è prezioso.

## Cosa puoi fare

- Correggere typo o imprecisioni
- Migliorare esempi e snippet
- Aggiungere chiarimenti su concetti ostici
- Tradurre capitoli
- Rivedere la coerenza tra `course/` e `docs/`

## Prima di contribuire

- Apri una [issue](https://github.com/CoachGodzup/python_book/issues/new) per discutere cambiamenti significativi
- Per piccole correzioni, vai diretto con una Pull Request

## Setup

```sh
# serve pandoc per buildare l'epub
make all

# controlli automatici
make check
```

## Linee guida

- Scrivi in italiano (salvo termini tecnici)
- Usa markdown pulito e leggibile
- Mantieni lo stile e la terminologia esistenti
